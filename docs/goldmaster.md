# Independent Astrology Gold-Master Validation

## What this is

The application's chart engine is compared **numerically** against an
independent implementation of the **Swiss Ephemeris 2.10.03** — the de-facto
industry standard used by Astro.com, AstroSeek, and most consumer astrology
software. The reference values were generated by `swisseph-wasm` (a
WebAssembly port of the Swiss Ephemeris) and committed to
`docs/goldmaster/fixtures.json`. The comparison tests read only the committed
JSON, so the GPL dependency is never needed at test time or in the shipped
application.

## How it was generated

- `npm run goldmaster:generate` → `scripts/generate-goldmaster.mjs` runs the
  Swiss Ephemeris WASM for a spread of charts and writes
  `docs/goldmaster/fixtures.json`.
- Each fixture records, for known-time charts: the resolved UTC instant,
  latitude/longitude, the SE Julian day, Sun→Pluto longitudes (DMS + sign),
  SE mean node and true node, Ascendant, MC, all 12 Placidus cusps, and the
  Sabian degree + global index under the degree-to-next convention.
- The unknown-time fixture records date-anchored placements only.

### Bug found and fixed by this comparison

The gold-master exposed that the Ascendant scan previously used a 0.5°
bracket width while scanning at 0.1°, causing the bisection to converge up to
0.5° off. After aligning the bracket width with the scan step, the Ascendant
agrees with the Swiss Ephemeris to < 0.01°.

### North Node result

The application's node (osculating ascending node) is compared against both
the SE **mean node** and the SE **true node**:

- The engine node typically sits between SE mean and SE true (both recorded
  in the fixture), and the gold-master test asserts agreement with the SE true
  node within a documented 1.5° tolerance while never landing on the
  descending node.
- Exact agreement is not expected: the engine computes an osculating node
  from state vectors, which differs slightly from SE's mean/true treatment.
  **Task 3 (nodeMode) resolves this convention explicitly.**

## Licensing note (important for commercialization)

`swisseph-wasm` and the Swiss Ephemeris are licensed **GPL-3.0-or-later /
AGPL** (Astrodienst offers a commercial license for closed-source use). This
project uses the Swiss Ephemeris **only as a dev-time validation reference**;
the runtime chart engine remains `astronomy-engine` (MIT). The GPL WASM module
is a devDependency and never ships in the application or its bundles.

**Decision required before commercial launch:** either (a) keep
astronomy-engine (MIT) as the runtime engine and continue validating against
SE as a reference, or (b) license the Swiss Ephemeris commercially from
Astrodienst and switch the runtime engine to it. Option (a) is fully
consistent with the original brief's requirement to isolate the calculation
library behind an adapter.
